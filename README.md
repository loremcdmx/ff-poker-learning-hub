# FF Poker Learning Hub

Отдельный статический обучающий хаб с девятью интерактивными уроками по префлопу и постфлопу и полноценным покерным симулятором:

**Production:** https://ff-poker-learning-hub.vercel.app

1. **Опен-рейзы по позициям** — диапазоны RFI от EP до BTN и практика на движке симулятора.
2. **SB без опена до Hero** — широкий вход, разделение диапазона на комплит/рейз и переход к open-shove по стеку.
3. **Против одного рейзера в свободных позициях** — колл, 3-бет и 3-бет-пуш с учётом позиций, сайзинга и стека.
4. **SB против одного рейзера** — отдельная логика продолжения без позиции.
5. **Защита BB коллом** — цена колла, сайзинги и диапазоны защиты против пяти позиций.
6. **Рестилы в коротких стеках** — EV пуша, профили соперников и практические раздачи.
7. **C-bet IP против BB** — структуры флопа, размеры и разделение методики с наблюдаемой игрой поля.
8. **Чек-рейз флопа** — узел BB против c-bet CO/BTN после защиты стила, примеры value/полублефов и два бесконечных режима практики.
9. **Защита против 3-бета** — fold/call/4-bet после собственного RFI с поправками на позицию, размер и стек.
10. **Покерный симулятор** — свободная игра за 1–4 столами против соперников разной силы, с фидбеком, статистикой и повторами.

Новые страницы повторяют общий учебный алгоритм хаба: первое решение внутри функционального покерного стола → три короткие опоры → проверенный срез поля → при наличии hand-level evidence библиотека примеров → локальная практика с разбором. Наблюдаемые частоты FF всегда отделены от методических ориентиров и не выдаются за solver-optimal стратегию.

## Наблюдаемые данные

Наблюдаемый слой публикуется только из полного проверенного окна: сначала
выбирается последняя версия раздачи, затем применяются poker-фильтры, а каждая
частота считается из целых счётчиков при `N >= 50` без сглаживания и модельного
заполнения. Сравнительный hand-chart доступен только при `169/169` руках во
всех заявленных когортах.

Текущий snapshot проходит обязательный data gate `6/6`: benchmark, RFI,
resteal rank-at-hand, c-bet, check-raise и VS3 используют проверенные
source-backed артефакты. Неполная комбинация не превращается в серую кнопку:
интерфейс показывает либо честно подписанный агрегат из целых счётчиков, либо
контекстный каталог только из полных сценариев. Подробные определения и
provenance находятся рядом с уроками в `assets/poker-*/research/README.md` и
`assets/poker-*/tools/README*.md`. Приватные hand histories, nicknames и
player IDs в хаб не копируются.

## Проверка

```bash
npm run check
npm run check:release-data
npm run check:release
npm run dev
```

`npm run check` проверяет runtime и контракты уроков. Только
`npm run check:release` является полным релизным гейтом: он дополнительно
требует готовности всех обязательных наблюдаемых источников.

После запуска откройте `http://127.0.0.1:4173`. Локальный сервер поддерживает те же чистые URL, что и Vercel, например `/rfi-open-position-lesson`, `/flop-checkraise-lesson` и `/poker-simulator`.

## Структура

- `index.html`, `hub.css` — отдельная главная хаба;
- `rfi-open-position-lesson.html` — опен-рейзы;
- `sb-unopened-lesson.html` — SB без опена до Hero;
- `vs-one-raiser-positions-lesson.html` — против одного рейзера в свободных позициях;
- `vs-one-raiser-sb-lesson.html` — SB против одного рейзера;
- `bb-call-defense-lesson.html` — защита BB;
- `resteal-lesson.html` — рестилы;
- `flop-cbet-hu-lesson.html` — c-bet IP против BB;
- `flop-checkraise-lesson.html` — чек-рейз BB против c-bet после защиты от CO/BTN стила;
- `vs-3bet-defense-lesson.html` — защита собственного опена на 3-бет;
- `poker-simulator.html` — самостоятельный симулятор и общий движок практики уроков;
- `assets/` — общий UI-kit, симулятор и данные уроков.

Исходники уроков собраны из рабочего среза `ff-start-poker-hub` и зафиксированы здесь как самостоятельный deployable snapshot.
